# SCOPE Studio

SCOPE Studio turns a founder's brand brief into a **6-pillar brand strategy** (mission, vision,
persona, values, voice/tone, promise), generated by AI, edited on an interactive canvas, and refined
through an AI copilot. Two processes: a **TanStack Start / React 19 / Vite / Tailwind v4** frontend
(`src/`) and a **FastAPI / LangGraph / DSPy** backend (`backend/app/`) on `:8000` using **OpenRouter**
as the LLM gateway (not the Anthropic API). The frontend hardcodes the backend at
`http://localhost:8000` in `src/lib/api.ts`.

## Run it

- Frontend (bun): `bun run dev`, `bun run build` (build + typecheck gate), `bun run lint`, `bun run format`.
- Backend (from `backend/`, Python 3.11): `pip install -r requirements.txt` then
  `uvicorn app.main:app --reload --port 8000`. Or `docker compose up` for api + Postgres.
- Backend needs `backend/.env` with `OPENROUTER_API_KEY` (see `backend/app/core/config.py`).
- No test suite — validate frontend with `bun run build`, backend with `python -c "import app.main"`.

## Data flow (keyed by `session_id`)

1. **Brief intake** — `src/routes/identity.tsx` → `/api/brief/analyze` → DSPy chain in
   `backend/app/agents/prompt_pipeline.py` (`EnhanceBriefPrompt → GenerateMarketingBrief →
   EvaluateBriefQuality`, retries once on eval failure). Region-aware: `usa` / `mena` / `gcc`.
2. **Approve** (`/api/brief/approve`) unlocks the canvas.
3. **Canvas** — `src/routes/canvas.tsx`, pillars as a radial orbital timeline
   (`src/components/ui/radial-orbital-timeline`) + `BrandGraph3D.tsx` (three.js / react-three-fiber).
   State in `src/components/scope/CanvasContext.tsx` (`useCanvas`).
4. **Copilot chat** — `src/components/scope/CopilotChat.tsx` → `/api/chat` → LangGraph agent in
   `backend/app/agents/brand_agent.py` (`prepare_context → chatbot → tool_handler → END`). Its tool
   `create_brand_node` proposes pillar revisions the frontend reconciles onto the active node.
5. Downstream: marketing analysis (`/api/marketing`), logo concept (`/api/logo`), export.

Backend layout: `api/` routers · `agents/` LLM logic · `schemas/` Pydantic I/O · `db/models.py` ·
`core/` config/database/security. `main.py` is entry point only.

## Prompt system — the fragile part (read before editing `agents/`)

All system prompts live in `backend/app/agents/prompts/__init__.py` (`SYSTEM_PROMPT_1..17` plus the
route-facing `BRAND_ARCHITECT_PROMPT`, `MARKETING_SYSTEM_PROMPT`, `LOGO_SYSTEM_PROMPT`,
`BRIEF_SYSTEM_PROMPT`). When rewording prompt text:

- **Preserve every `{placeholder}`** — `prompt_pipeline.py` and routes inject them.
- **Keep "respond ONLY with raw JSON, no markdown" rules verbatim** — routes parse the output as JSON and
  the JSON **key names are the API contract**, mirrored by the TS types in `src/lib/api.ts`. Never rename keys.
- Keep `brand_agent.py`'s behavior: `create_brand_node` called **six times** on approval, and the
  `[AUTO-GENERATE]` shortcut prefix.
- **Extend, never weaken** the anti-slop banned-buzzword list in `BRAND_ARCHITECT_PROMPT`.

## Frontend conventions

- Path alias `@/` → `src/`. UI primitives (shadcn-style) in `src/components/ui/`; app composites in
  `src/components/scope/`. Routes are file-based; **never hand-edit `src/routeTree.gen.ts`**.
- Copilot UI is **bilingual en/ar with RTL** — copy in the `T` / `CHOICES` tables in `CopilotChat.tsx`,
  `dir="rtl"` flips layout. Keep both languages in sync.
- `localStorage`: chat mode `scope_chat_mode` (`free`/`guided`), auth token `scope_token`. Tailwind v4
  with CSS custom props (`--scope-purple`, `--gradient-brand`, …) in `src/styles.css`.
