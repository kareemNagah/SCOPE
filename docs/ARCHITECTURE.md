# SCOPE Studio — Architecture & Ground Truth

> Living inventory produced in **Task 0** of `Build prompt.md` and updated after Tasks 0.5–4.
> Captures the current implementation paths, contracts, state model, and known validation constraints.

## 1. What it is

SCOPE Studio turns a founder's brief into a 6-pillar brand strategy (mission, vision, persona, values,
voice/tone, promise), generated by AI, edited on an interactive canvas, and refined via an AI copilot —
then carried through Identity → Logo → Export. Two processes:

- **Frontend** — TanStack Start + React 19 + Vite 7 + Tailwind v4 (`src/`), three.js / react-three-fiber.
  Path alias `@/` → `src/`. Talks to the backend over HTTP, hardcoded at `http://localhost:8000`
  (`src/lib/api.ts`).
- **Backend** — FastAPI + LangGraph + DSPy (`backend/app/`) on `:8000`, async SQLAlchemy + asyncpg
  (Postgres). **All LLM + image calls go through OpenRouter**, not the Anthropic or Google APIs directly.

## 2. Step flow (user journey)

`src/components/scope/Journey.tsx` (`JourneyStepper`) renders the rail:

**Brief → Strategy → Identity → Logo → Export**

| Step | Route | Purpose |
|------|-------|---------|
| Brief | `src/routes/index.tsx` | Prompt entry, brief generation, saved-briefs list |
| Strategy | `src/routes/canvas.tsx` | 6-pillar radial orbital timeline + 3D graph + copilot chat |
| Identity | `src/routes/identity.tsx` | Session-aware palette / type-pairing / logo-concept selection |
| Logo | `src/routes/logo.tsx` | Logo studio (wordmark, concept, palette, typography → generate + SVG download) |
| Export | `src/routes/export.tsx` | Brand-package export |
| *(off-rail)* | `src/routes/marketing.tsx` | Marketing analysis (personas, hooks) — not in the rail |
| *(auth)* | `signin.tsx` / `signup.tsx` | Auth |

**Gating** (`useSessionBriefStatus`): Strategy unlocks on `brief.approved === true`; Identity/Logo/Export
unlock on `brief.strategy_confirmed === true`.

## 3. Backend map (`backend/app/`)

### Routers (`api/`)
- `brief.py` — `POST /api/brief/analyze` (multipart: text + reference images), `POST /api/brief/approve/{session_id}`,
  `POST /api/brief/confirm-strategy/{session_id}`, `GET /api/brief/{session_id}`, `GET /api/briefs`,
  `GET /api/brief/identity-preview/{session_id}`.
- `chat.py` — `POST /api/chat`, `GET /api/nodes/{session_id}`, `GET /api/history/{session_id}`,
  `POST /api/restore/{session_id}/{version}`, `GET /api/chat/history/{session_id}`.
- `marketing.py` — `POST /api/marketing/analyze`, `GET /api/marketing/{session_id}`.
- `logo.py` — `POST /api/logo/generate`, `GET /api/logo/{session_id}`.
- `auth.py` — `POST /api/auth/signup|signin`, `GET /api/auth/me` (JWT HS256, bcrypt).
- `health.py` — `GET /api/health` (status, db dialect, checkpointer type, env).

`main.py` is an entry point only: CORS, router registration, lifespan (`create_tables` on startup —
with manual `ALTER TABLE` dev migrations in `core/database.py` — `dispose_engine` on shutdown).

### LangGraph copilot agent (`agents/brand_agent.py`)
- **`AgentState`** (TypedDict): `session_id`, `region`, `conversation_mode` (`free`|`guided`),
  `focus_node_type|title|value`, `brief_context`, `messages` (`Annotated[..., add_messages]`),
  `proposed_nodes`, `proposed_palettes`.
- **Graph**: `START → prepare_context → chatbot → (should_continue) → tool_handler → chatbot | END`.
- **Tools**: `create_brand_node(title, content, type∈{mission,persona,positioning,values,tone,vision})`
  and `suggest_color_palette(rationale, palettes[], recommended)`.
- **Checkpointer**: **`MemorySaver` (in-memory)**. `thread_id = f"{session_id}:{md5(brief)}"`. State is
  loaded/updated via `aget_state` / `aupdate_state` / `ainvoke`.

### DSPy brief pipeline (`agents/prompt_pipeline.py`)
Linear chain `EnhanceBriefPrompt → GenerateMarketingBrief → EvaluateBriefQuality`; re-runs generation
once with the evaluator's issues if `passed == False`. `normalize_region` maps aliases →
`usa` / `mena` / `gcc`. Runs under `dspy.context(lm=create_dspy_lm(), adapter=dspy.JSONAdapter())`,
returns a `BriefPipelineResult` dataclass.

### Prompts (`agents/prompts/__init__.py`, ~803 lines) — fragile, an API contract
`SYSTEM_PROMPT_1..17` (multi-phase creative prompts) plus the route-facing `BRAND_ARCHITECT_PROMPT`
(anti-slop banned-buzzword list; calls `create_brand_node` **six times** on approval; `[AUTO-GENERATE]`
shortcut), `MARKETING_SYSTEM_PROMPT`, `LOGO_SYSTEM_PROMPT`, `BRIEF_SYSTEM_PROMPT`. The last three emit
**strict JSON** whose keys mirror `src/lib/api.ts` types. Rules: preserve every `{placeholder}`, keep
"respond ONLY with raw JSON" verbatim, never rename keys.

### LLM + image gateway (`core/config.py`, `agents/model_factory.py`)
- OpenRouter base `https://openrouter.ai/api/v1`; key alias `OPENROUTER_API_KEY` | `OPENAI_API_KEY`
  (base alias `OPENROUTER_BASE_URL` | `OPENAI_API_BASE`).
- Models: `scope_text_model = google/gemini-2.5-flash`;
  `scope_multimodal_model = scope_image_model = google/gemini-3.1-flash-image-preview`.
- Helpers: `create_langchain_chat_llm`, `create_dspy_lm` (prepends `openai/` for LiteLLM↔OpenRouter),
  and **`openrouter_chat_completion(..., model, messages, modalities=["image","text"], ...)`** — the
  async HTTP path used for multimodal/image requests.

### Image generation TODAY
Only in `logo.py:62-86`: calls `openrouter_chat_completion(model=scope_image_model,
modalities=["image","text"])`, then reads the generated image from
`message["images"][0]["image_url"]["url"]` and persists it to `DBLogoResult.generated_image`. **No
`@google/genai` / `google-genai` SDK, no DALL-E / Replicate / Stability** anywhere. The Build roadmap
extends *this* OpenRouter path (single gateway, single key) rather than adding a second SDK.

### Persistence model (`db/models.py`)
Durable state is **Postgres rows keyed by `session_id`** (LangGraph's `MemorySaver` is only the
in-process conversation checkpoint):
`DBUser`, `DBBrief` (brand_name, industry, summary, pillars, visual_cues, competitive_signals, region,
marketing_standards, `approved`, `strategy_confirmed`), `DBBrandNode` (versioned, `is_active`),
`DBChatMessage`, `DBMarketingResult`, `DBLogoResult` (concept_description, tagline, variations,
`generated_image`).

## 4. Frontend ↔ backend contract

`src/lib/api.ts` (base `http://localhost:8000`) exposes: `signup/signin/me/logout`; `analyzeBrief`,
`getBrief`, `approveBrief`, `confirmStrategy`, `getMyBriefs`, `identityPreview`; `chat`, `getNodes`,
`getHistory`, `restoreVersion`, `getChatHistory`; `analyzeMarketing`, `getMarketing`; `generateLogo`,
`getLogo`; `health`. Auth token in `localStorage.scope_token` (Bearer); user cached in `scope_user`;
`session_id` passed per call. Key types: `BrandNode{type,title,content}`,
`ChatResponse{response,mode,suggestions,nodes,proposed_palettes}`, `ChatMode = "free"|"guided"`,
`BriefResult{...}`, `LogoResult{concept_description,tagline,variations,generated_image?}`,
`MarketingResult{blueprint,personas,hooks}`.

Canvas state: `src/components/scope/CanvasContext.tsx` (`useCanvas`) holds `nodes`, `activeNodeId`,
`editingNodeId`, `recentEdits`, `selectedPalette`, with `applyDraftToNode`. Copilot UI:
`src/components/scope/CopilotChat.tsx` — bilingual en/ar via `T` / `CHOICES` tables, `dir="rtl"`, chat
mode in `localStorage.scope_chat_mode`; assistant replies render a constrained Markdown subset
(headings, lists, quotes, links, inline/code blocks, bold/italic) without injecting raw HTML.

Identity handoff uses local browser memory:
`scope_selected_palette:{session_id}` stores the chat/identity selected palette, while
`scope_last_palette`, `scope_last_font`, `scope_last_concept`, and `scope_last_wordmark` pre-populate
the standalone Identity and Logo routes. Durable strategy source remains the backend.

## 5. Tooling & validation

- **Frontend** (bun): `bun run dev`, `bun run build` (build + typecheck gate), `bun run lint`,
  `bun run format`. Known WSL/sandbox caveats: `bun` may not be installed in agent environments; Vite can
  attempt writes under `node_modules/.vite-temp`; the custom WSL module-runner timeout can make build/type
  checks run longer than bounded agent commands. Prefer a local developer shell for final `bun run build`.
- **Backend** (Python 3.11, from `backend/`): `pip install -r requirements.txt`,
  `uvicorn app.main:app --reload --port 8000`; or `docker compose up` (api `:8000`, db `:5432`). Needs
  `backend/.env` with `OPENROUTER_API_KEY`.
- **Tests DO exist** (correcting the older "no test suite" note): `backend/tests/test_brief_utils.py`,
  `test_prompt_pipeline.py`, `test_session_access.py` → run `pytest` from `backend/`. Import smoke check:
  `python -c "import app.main"`.

## 6. Task 0.5–4 implementation notes

- Live strategy and identity paths no longer rely on the old SCOPE/demo defaults for the wordmark or
  placeholder strategy content. Logo wordmark is empty until populated from brief/session memory.
- Chat supports guided/free mode, focus-node context, generated next-move suggestions, AI palette
  suggestions, and session-scoped selected palette memory.
- Identity preview is served by `GET /api/brief/identity-preview/{session_id}`, combining the confirmed
  brief, visual cues/direction, and active strategy node summaries.
- Logo Studio reads remembered identity selections, renders on a white artboard, calls
  `/api/logo/generate`, and exports the current preview as SVG.

**Legitimate product chrome (keep):** page `<title>` / og tags, `src/components/scope/ScopeLogo.tsx`,
`scope_site_name` config, and `"SCOPE"` inside test fixtures.

## 7. Arabic / RTL status

Partial today: `src/routes/index.tsx` brand-name input and `CopilotChat.tsx` (full en/ar `T` / `CHOICES`,
`dir="rtl"`). Missing on Identity / Logo / Marketing / Export; no dedicated Arabic display face or
`html[lang="ar"]` rules in `src/styles.css`. Cross-cutting target: `dir="auto"` on generated text, an
Arabic display face, and logical CSS properties across the remaining routes.
